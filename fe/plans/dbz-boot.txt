# Dragon Ball Z: Attack of the Saiyans (USA, BRPE) — get past the title into play.
#
# WHY THIS PLAN EXISTS: the first probe run sent NO input, so the game sat on its
# title screen for the whole run and every published Action Replay address read
# exactly 0. A control address read real data, which proves the probe worked and
# the party structure simply had not been allocated yet. This plan drives the game
# far enough that the structure exists.
#
# ⛔ THE BUTTON THAT DISMISSES A MODAL IS THE EXPENSIVE LESSON IN THIS PROJECT.
# A scripted tutorial or name-entry screen silently swallows all other input, and
# the reader then gets blamed for reading nothing. Mash A to advance; press B (not
# A) to dismiss anything that re-triggers on A. If the run shows no state change,
# suspect a modal before suspecting the memory map.
#
# The ROM is 128 MB and booting it takes a while, so the first press is late.
