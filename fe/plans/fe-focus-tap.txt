# FE11 + save: focus Continue with UP (button), then CONFIRM with a touch tap on it.
#
# \u26d4 HYPOTHESIS, from two measurements:
#   * A single tap on NEW GAME advanced the screen (to the difficulty screen). The cursor ALREADY
#     sat on New Game, so that tap was "confirm the focused panel", not "move focus".
#   * A tap on CONTINUE changed only the description strip (x16..131, y174..183) -- i.e. it MOVED
#     THE FOCUS to Continue, and did not confirm.
# So a tap both focuses and, when the panel is already focused, confirms. Combining the two proven
# halves -- UP to focus Continue, then tap it -- should confirm.
#
# Button boxes measured on the bottom screen (button-box3.py): rows at y 62 / 102 / 142,
# left column x centre 67. Left column top-to-bottom = Continue / Suspend Point / New Game.
