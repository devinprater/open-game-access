# Dragon Ball Z: Attack of the Saiyans (USA, BRPE) — try to open a MENU.
#
# WHY: the character list at 0x020CC774 holds Piccolo/Krillin/Tien while the player
# has Goku alone. A party/menu screen NAMES its contents, so it is the one screen that
# can confirm or refute what that list means. The filmstrip (DBZ_SHOT_DIR) records
# every sample point, so one run shows whether a menu actually opened — no need to
# guess from a single end-of-run shot.
#
# ⛔ THE BOOT GATE: this ROM opens on "Resetting backup memory. Press the A Button to
# begin." (verified by screenshot). Without an A press the game sits there for the
# whole run — which is exactly how an earlier control run tested nothing. So A is
# pressed early and repeatedly until the game is demonstrably running.
#
# Then, in the house scene, this plan tries the usual DS RPG menu keys in sequence,
# spaced widely enough that each attempt is visible in the filmstrip:
#   X     - very common menu key on DS RPGs
#   START - the other common one
#   Y     - occasionally used
# Between attempts it returns to "no menu" with B, so a failed attempt does not leave
# the game in a submenu and mask the next key.
