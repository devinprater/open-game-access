# ⛔ WHY. Enemy detection cannot be verified on the map units.txt reaches: its
# faction census is player=1, enemy=0 for the whole run, so "Next enemy" correctly
# answers "No enemies found" and proves nothing about the code path. Verifying it
# needs a hostile faction present.
#
# This plan mashes A through the remaining dialogue (which is what advances and
# dismisses both story text and tutorials), interleaves START (end turn / skip), and
# then ends turn repeatedly — ending a turn is what triggers the enemy phase, so it is
# the most likely action to make a hostile force appear if one is pending.
#
# Spacing is deliberately wide (100+ frames apart): presses too close together get
# swallowed by text boxes that are still animating, which looks like "the game did
# not advance".
#
# Read the result with: wsl.sh fe-enemy 40000 enemies
