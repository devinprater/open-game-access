# WHY THIS IS A SEPARATE PLAN FROM dbz-boot.txt: the boot plan reached an intro
# dialogue scene with Krillin (verified by screenshot), which is past the title but
# BEFORE any combat. The published Action Replay addresses name party HP/Ki/AP —
# values that a battle writes — so they read 0 until a fight happens.
#
# ⛔ DO NOT CONCLUDE THE ADDRESSES ARE WRONG FROM A ZERO READING. Measure whether
# the window is populated instead, and use the probe's [trace] lines to see which
# frame the party block fills in. A structure that never appears means we never
# reached the right state, which is a different problem from a bad address.
#
# The 128 MB ROM is slow to boot, so presses start late and are widely spaced.
