# DBZ: Attack of the Saiyans (USA, BRPE) — SKIP THE CUTSCENE, THEN FIND THE MENU.
#
# WHAT WE KNOW (verified, see docs/reverse-engineering/dbz-attack-of-the-saiyans.md):
#   * START on the cutscene opens a two-item box reading "Skip" / "Back"
#     (docs/evidence/dbz-menu-attempts.png). X and Y do nothing there.
#   * The game is still inside its opening cutscene at f=14000 — it never reached
#     free gameplay in any run so far.
#   * The character list at 0x020CC774 holds Piccolo/Krillin/Tien and is populated
#     once the game is running. A PARTY/STATUS screen names its contents, so that is
#     the one screen that can test what the list means.
#
# STRATEGY: use the cutscene's own "Skip" option to reach gameplay, then try the menu
# keys in GAMEPLAY (where a party menu actually exists), not in the cutscene.
#
# ⛔ READ THE PANELS AT 4x, ONE AT A TIME. A previous run's conclusion about the
# opening scene ("Goku's house, Krillin speaking") was WRONG because it was read from
# a 2x contact sheet — the truth was Kame House with Launch. Contact sheets spot which
# frame changed; they cannot be read for content.
