# Fire Emblem: Shadow Dragon (USA) — play the Prologue deliberately, step by step.
#
# ⛔ WHY THIS PLAN IS SHAPED THIS WAY.
# The Prologue is a chain of scripted movement tutorials. A pure-A mash stalls on the
# first one ("Marth can move anywhere within the blue area") because the tutorial waits
# for the unit to MOVE. A play plan that moves works — screenshots proved Marth can be
# walked from (1,20) to (5,20) and the Wait menu opened — but the *next* tutorial wants
# a different direction, and the only way to know which is to read the top screen.
#
# So each "beat" below is: select -> move a short distance -> confirm -> Wait -> clear
# any popup -> end turn. Repeating beats with alternating directions walks the chain.
# Screenshots at the end of each beat are what confirm progress; see fe-tutorial-steps.py.
#
# Frames are wide apart on purpose: menu transitions and text animate, and presses too
# close together are swallowed, which looks exactly like "the game ignored the input".
