# Fire Emblem: Shadow Dragon (USA) — Prologue, with the correct action ORDER.
#
# ⛔ WHAT THE SCREENSHOTS SHOWED, AND WHY THE EARLIER PLAN STALLED.
# Beat screenshots showed the bottom screen with Marth selected, a blue movement-range
# overlay, and the instruction "...to move to, then press A" — while the TOP screen still
# displayed the "Waiting" tutorial popup ("After a unit moves, select 'Wait' ... You can
# also press B or touch the B icon at the top of the screen to cancel the move.").
#
# Two things follow:
#   1. That popup must be DISMISSED (B, per its own text) before map input is accepted.
#      Pressing A with the popup up just re-reads the popup — which is precisely how a
#      plan loops forever while looking like it is "stuck on the tutorial".
#   2. Selection is not a separate step to confirm. The sequence the game wants is:
#        A (select unit) -> DIRECTION (move cursor to destination) -> A (commit)
#        -> A (action menu: first entry is Wait) -> B (dismiss the popup)
#
# So each beat is:  A, move, A, A, B
# The B is what breaks the loop the earlier plan got stuck in.
