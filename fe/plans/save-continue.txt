# FE11 (USA) with a SAVE: main menu -> Continue -> into the saved chapter.
#
# ⛔ THIS PLAN USED TO BE WRONG, and the way it was wrong is the point of this file.
#
# It pressed A five times from f1200 with NO DIRECTION. Screenshots of that run show the game
# playing the PROLOGUE narration ("A young man hailing from the Altea region...") -- i.e. it had
# chosen NEW GAME, not Continue, so the save was never used and the chapter was never reached.
#
# Why: the main menu is a 2-COLUMN GRID, not a vertical list, and the cursor STARTS on New Game:
#
#       left column   : Continue / Suspend Point / New Game     <- cursor starts HERE
#       right column  : Copy Data / Erase Data / Extras
#
# So Continue is the row ABOVE New Game, reached with UP -- not DOWN, and not by pressing A.
# Measured: after one UP the bottom description bar OCRs as "[.]Continue from save data".
#
# ⛔ AND THE TIMING WAS WRONG TOO. The menu is not up at f1200; shots there read "TOUCH TO START".
# START at f1600 + A at f2400 is the measured arrival, which is what this plan now uses.
#
# ⛔ THE BOTTOM DESCRIPTION BAR NAMES THE LIVE ROW -- OCR it (scripts/fe-ocr.sh). Reading a
# downscaled capture produced contradictory descriptions of the same image during this work.

# --- title -> main menu (measured timing) ---
KEY 1600 START 1
KEY 1618 START 0
KEY 2400 A 1
KEY 2418 A 0
SHOT 2800 /home/devin/fe/out/sc-0-menu.ppm 1

# --- UP once to Continue ---
KEY 3000 UP 1
KEY 3018 UP 0
SHOT 3300 /home/devin/fe/out/sc-1-continue.ppm 1
