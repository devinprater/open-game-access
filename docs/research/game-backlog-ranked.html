Game Backlog — Ranked Easy to Hard

Every system in Dropbox\Games, ordered by how much work an accessibility adapter would be. Open Game Access, 2026-09-16.

The core outranks the game. A game we cannot boot is harder than any game we can. An adapter cannot be written or tested without a running core, so the system is the first gate — and it beats everything the game itself would suggest.

The honest shortlist is NDS and GB/GBC/GBA. Everything else is gated behind core work unrelated to accessibility.

Reader families

  • (A) Text buffer / printer — dialogue is readable state. Easiest.
  • (B) Menu / list state — cursors, selections, counts. Moderate.
  • (C) Map / grid / position — needs a coordinate model. Moderate to hard.
  • (D) Real-time sprite / hitbox — the player must react within frames. A wall.

No adapter fixes a type D game. Mortal Kombat 1’s answer — turning opponent state into categorical sounds — is a design solution that a post-hoc reader can only approximate.

What the inventory implies

  1. Finish what is started. Fire Emblem: Shadow Dragon is wired in and needs verification, not features.
  2. Attack of the Saiyans next — turn-based, addresses already public, NDS core working. Genuinely the easiest new target.
  3. Then the Pokémon gen-4/5 family, reusing the Black/White reader.
  4. Do not start a game on a system with no core. Fire Emblem: Awakening, Pokémon ORAS, Final Fantasy Tactics: War of the Lions, Steins;Gate and Chrono Cross are all easy games behind a hard wall.
The collection is overwhelmingly fighting games. Roughly 40 of ~130 titles are fighting games, and another 20 are beat-em-ups or action. That is the single hardest genre, and it is the majority of the library. A ranked list is therefore not enough here — most of it sits in Tier 3/4. For this collection the MK1 categorical-sound approach is the only thing that could ever make the fighting games playable, and that is a design project rather than a RAM reader. Worth deciding deliberately whether it is in scope.

The PS1 / PS2 question

PS1 and PS2 BIOS and firmware are present, and those two systems have an advantage the Nintendo ones do not: the DBZ Tenkaichi mod shows PS2 RAM is reachable over PINE (PCSX2’s socket IPC) with no base-pointer chasing, and PS1 emulators have a mature memory-access story. If a PS1 or PS2 core were integrated, a large block of this library becomes reachable — including the fighting games, where the BT2 mod is a working precedent to copy. That is a bigger project than an adapter, but it unlocks far more of this collection than any single NDS game will.

Verification status of the Attack of the Saiyans addresses

The probe run — 6000 frames, no input sent — read exactly 0 at every published Action Replay address, while a control address returned real non-zero data. That is the documented “region entirely zero” signal: the party structure had not been allocated yet, because with no input the game never left its title screen. It is not evidence the addresses are wrong.

Next step: drive input past the title into a battle and re-measure. Until then the AotS addresses are claims, not findings.
