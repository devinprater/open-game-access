# Mod-mining notes

Sarah's working notes from studying other people's accessibility mods — what they do, how they do it, and what Open Game Access can learn from them. The distilled lessons live in the tricks catalogue, [../accessibility-tricks.md](../accessibility-tricks.md) (§§1–33); the files here are the dated source notes the catalogue was distilled from.

- `ff-mods-mining-2026-11-06.md` — the three Final Fantasy screen-reader mods (FFPRCore-Screen-Reader for FF I–VI Pixel Remaster, FFX-X2-Screen-Reader, and Blind Soldier for the original FF7 PC): packages grabbed, checksums verified, source read. Source of catalogue §32.
- `ff32-adapter-implementation-2026-11-06.md` — the follow-through: an audit of OGA's existing adapters against §32, and the two findings implemented (a Dragon Ball Z city-damage warning latch-and-re-arm, and ordinals for Dragon Quest 9's nearby-object cycle).
- `jvpa-mining-2026-11-04.md` — package-level mining of seven JVPA poker-mod packages: what each contains and what transfers to OGA. Source of catalogue §29.
- `jvpa-source-mining-2026-11-05.md` — the deeper pass over the JVPA mods' decoded Lua source code. Source of catalogue §31.
- `games-crosscheck.md` — the running crosscheck list: games checked against existing community accessibility mods and reference implementations (including Pokémon Access Plus, Sticky Business Access, and finds from the AudioGames forum harvest), with what each is worth mining for.
